# Seasonal Agriculture Performance Analysis

## About the Project

This project analyzes agricultural performance across different seasons
using data analytics techniques.

## Dataset

- 4,000 farm-level records
- 8 Indian states
- 8 crops
- 3 seasons: Kharif, Rabi and Zaid
- 28 columns

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook / Google Colab

## Analysis Performed

- Data cleaning
- Missing-value handling
- Duplicate removal
- Descriptive statistics
- Outlier analysis
- Univariate analysis
- Bivariate analysis
- Multivariate analysis
- Seasonal performance comparison

## Key Findings

- Kharif has the largest share of records.
- Kharif has the highest average yield.
- Kharif also has the highest average profit.
- Zaid records a net average loss.
- Drip irrigation gives the best average yield.
- Sugarcane has the highest average profit by crop.
